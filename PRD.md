# PRD

## Goal

- Keep the Roth Conversion Calculator deployable as a compliant, SEO-focused tax education tool.

## Current Focus

- Feature or guard: turn Google Search Console queries into review-gated SEO content actions without creating personal tax recommendations.
- Affected surface: SEO monitoring playbook, content opportunity planning, compliance guardrails, source content, SEO copy.
- User-visible result: the site can grow from real search demand while keeping calculator, bracket, state, and tax-interaction content educational and assumption-based.

## Acceptance Criteria

- [x] AI guardrails detect recommendation, optimal-action, and absolute-accuracy phrasing.
- [x] A source-content test scans user-facing `src` files for high-risk direct claims.
- [x] Project memory records the guard so future V1.3 work keeps the same boundary.
- [x] Search Console query clusters map to target surfaces, safe actions, and compliance/professional review gates.
