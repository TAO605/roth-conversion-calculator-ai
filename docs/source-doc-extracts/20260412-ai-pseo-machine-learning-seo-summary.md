## Recovered Core Ideas

- PSEO means programmatic SEO.
- AI can generate content and support manual, semi-automated, or automated publication workflows.
- The hard part is not merely publishing many pages; the hard part is knowing which pages are good, which pages are bad, and which future topics are likely to work.
- GA4 should be introduced as a feedback source after pages are published.
- Traditional SEO content generation can become blind writing when there is no feedback loop.
- AI plus GA4 can create a self-learning loop:
  - Success-rate learning: a search term or page that succeeds receives higher weight; failed content receives lower weight.
  - Traffic learning: page traffic contributes to the next scoring calculation.
  - Pattern learning: AI studies high-traffic article/page traits and proposes similar search terms or topic patterns.
- Suggested preparation in the source document:

  - Enable Google Analytics Data API.
  - Create a Service Account.
  - Download a JSON key.
  - Add the Service Account to GA4 with viewer access.
  - Let the backend use daily feedback, for example around 2 AM, to learn from high-performing and underperforming pages.

- Do not create one thin page for every keyword variant.
