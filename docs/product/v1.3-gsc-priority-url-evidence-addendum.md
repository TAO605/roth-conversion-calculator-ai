# V1.3 GSC Priority URL Evidence Addendum

Date: 2026-05-30

## Purpose

This addendum adds a deterministic preflight command for Google Search Console retry work. Before using URL Inspection or request-indexing again, the agent should verify that priority public URLs are crawlable, canonicalized correctly, present in the sitemap, and not marked `noindex`.

## Implemented Scope

- Added `scripts/gsc-evidence.mjs`.
- Added `npm run seo:gsc-evidence`.
- Added the evidence command to the `/seo-monitoring` Search Console submission loop.
- Added a methodology canonical fix: `/methodology` now declares `alternates.canonical`.

## Priority URLs

The command checks:

- `/`
- `/seo-monitoring`
- `/methodology`
- `/tax-data-update`
- `/tax-brackets/2026`
- `/roth-conversion-irmaa-guide`

## Checks

For each priority URL:

- HTTP status is `200`.
- Content type is HTML.
- Canonical matches the expected canonical URL.
- URL appears in `/sitemap.xml`.
- No `noindex` signal appears in meta robots or `x-robots-tag`.

## Operating Rule

If `npm run seo:gsc-evidence` fails, fix the source-level issue before retrying Search Console request-indexing.

If `npm run seo:gsc-evidence` passes but Google still returns a request-indexing error, treat the failure as a Search Console workflow exception and retry later rather than changing unrelated production code.
