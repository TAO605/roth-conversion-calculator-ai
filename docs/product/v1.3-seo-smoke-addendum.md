# V1.3 Engineering Addendum - SEO Smoke Command

Date: 2026-05-30

This addendum adds a repeatable technical SEO verification command for production and preview checks.

## Implemented

- Added `scripts/seo-smoke.mjs`.
- Added `npm run seo:smoke`.
- The command defaults to `https://www.roth-conversion-calculator-ai.shop`.
- `SEO_SMOKE_BASE_URL` can override the target for preview or local environments.

## Checks

- Homepage returns 200 and `text/html`.
- Homepage canonical matches the target base URL.
- Homepage contains required trust and conversion snippets: calculator title, educational estimate boundary, not-tax-advice boundary, CPA packet action, and tax professional review status.
- Homepage does not contain high-risk YMYL phrases such as absolute accuracy claims or direct conversion advice.
- `robots.txt` returns 200 and links sitemap, feed, and llms.txt.
- `sitemap.xml` returns 200, is XML, includes the canonical homepage, and does not include the bare apex domain.
- `llms.txt` returns 200 and includes methodology and tax-data-update URLs.

## Usage

```bash
npm run seo:smoke
```

For another host:

```bash
SEO_SMOKE_BASE_URL=https://preview.example.com npm run seo:smoke
```
