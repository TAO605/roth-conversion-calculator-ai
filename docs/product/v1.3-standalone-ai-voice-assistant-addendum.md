# V1.3 Standalone AI Voice Assistant Addendum

This addendum records the shift from a small voice-to-field helper to an independent AI voice assistant component.

## Implemented

- Added `AiVoiceAssistant` as a standalone below-results component.
- Supports text questions and browser speech recognition for one spoken question at a time.
- Sends educational questions through `/api/ai/explain`, preserving the existing server-side origin, rate-limit, paid-model fuse, fallback, and deterministic verifier boundaries.
- Supports browser read-aloud for the assistant answer through local speech synthesis.
- Keeps API keys and paid model configuration out of the browser.
- Removes the old `VoiceInputAssist` from the quick-input panel so the input area stays focused on manual calculator fields.

## Boundaries

- Voice capture remains browser-side and permission-gated.
- The assistant does not calculate final tax advice, recommend a personalized conversion amount, or replace qualified tax professional review.
- The old voice-to-field helper remains in source as a rollback/reference component but is disabled in the feature registry.

## Acceptance Evidence

- AI voice assistant tests cover API failure fallback, microphone permission denial, transcript capture, and protected API request payloads.
- Homepage performance tests require dynamic loading of `AiVoiceAssistant`.
- Calculator input layout tests require the old voice helper to stay out of the quick-estimate fields.
