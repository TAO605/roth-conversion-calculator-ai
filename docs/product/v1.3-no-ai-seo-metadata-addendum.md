# V1.3 No-AI SEO Metadata Addendum

Date: 2026-06-03

## Assessment

The P1 no-AI UI pass removed AI-first visible homepage copy, but the production HTML still contained `AI Roth Conversion Calculator` through SEO metadata, social preview metadata, RSS site title, and homepage `WebPage` JSON-LD.

This is a separate SEO surface from the optional AI explainer. Removing AI from metadata should not remove the AI explainer feature or its compliance controls.

## Implementation Scope

- Root page metadata title and description use `Roth Conversion Calculator 2026`.
- Open Graph and Twitter card titles use `Roth Conversion Calculator 2026`.
- `siteConfig.siteName` uses `Roth Conversion Calculator`, which updates RSS, Website JSON-LD, Organization JSON-LD, and publisher names.
- Homepage `WebPage` JSON-LD name uses `Roth Conversion Calculator 2026`.
- The optional AI explainer remains available as an educational explanation module below the result surface.

## Guardrails

- Do not remove WebApplication, WebSite, WebPage, HowTo, Organization, FAQPage, Article, or BreadcrumbList structured-data coverage.
- Do not change calculator math or tax data.
- Do not claim tax advice, guaranteed accuracy, optimal recommendations, or professional review completion.
- Keep a dedicated regression test for no-AI metadata branding.
