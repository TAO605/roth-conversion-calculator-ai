# V1.3 IRMAA Review Prep Addendum

Date: 2026-06-08

## Decision

The next IRMAA step is a review-prep module, not a Medicare premium amount calculator.

This keeps the site aligned with the V1.3 priority to surface hidden tax interactions while preserving the YMYL boundary that IRMAA depends on Medicare enrollment, MAGI, Part B and Part D context, SSA notices, lookback-year return data, and life-changing event review.

## Implemented

- Added `buildIrmaaReviewPrep` to create a deterministic review-prep object from existing calculator inputs.
- Added an `IRMAA Review Prep` section inside `Tax Impact Warnings`.
- Added IRMAA review-prep lines to the CPA packet.
- Retained official-reference links to Medicare.gov Part B costs and SSA Form SSA-44.
- Added tests proving the module exposes the 2026 premium-year / 2024 usual lookback-year context without calculating Medicare premium amounts.

## Boundaries

- The module uses current taxable income plus taxable conversion only as an income review proxy.
- It does not calculate Medicare MAGI.
- It does not calculate Part B or Part D premium increases.
- It does not decide whether a life-changing event applies.
- Married filing separately remains a separate review path instead of a simplified threshold calculation.

## Future P2 Work

A true IRMAA estimate module should not ship until it has:

- Dedicated MAGI inputs.
- Medicare enrollment and Part B/Part D context.
- Lookback-year tax return selection.
- SSA notice and life-changing-event handling.
- Official premium-year table data with source date metadata.
- Separate tests for each filing-status branch and table row.
- Professional-review status before changing public copy from review prep to amount estimate.
