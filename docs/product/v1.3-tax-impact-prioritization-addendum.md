# V1.3 Engineering Addendum - Tax Impact Prioritization

Date: 2026-05-30

This addendum supplements the V1.3 execution track with a safer version of hidden tax-impact detection.

## Implemented

- Converted the static `Tax Impact Warnings` panel into input-prioritized review items.
- Added `buildTaxImpactReviewItems` to label IRMAA, ACA premium tax credits, Social Security benefit taxation, NIIT MAGI-side review, RMDs, and state-specific rules as either standard review items or input-triggered review items.
- Used age, retirement age, state tax input, and a taxable-income proxy after conversion as prioritization signals.
- Linked each review item to an existing educational guide instead of expanding the result card into a full tax rules engine.
- Added tests for input-triggered labels, result-card placement, guide links, and no unsupported external-tax amount claims.

## Compliance Boundary

- The calculator still does not estimate IRMAA premiums, ACA subsidy changes, taxable Social Security benefits, NIIT owed, RMD amounts, AMT, tax credits, or state-specific deductions.
- The NIIT signal uses taxable income plus taxable conversion only as a MAGI-side review proxy. It is not a NIIT calculation and does not classify investment income.
- ACA review remains conditional because Marketplace coverage, household size, and subsidy reconciliation data are not collected.
- IRMAA review remains conditional because Medicare enrollment status, MAGI, lookback-year tax returns, and life-changing events are not collected.
