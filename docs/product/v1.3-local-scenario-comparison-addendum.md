# V1.3 Local Scenario Comparison Addendum

Date: 2026-06-10
Version: 1.0.222

## Purpose

This addendum closes the safest remaining V2-style scenario-comparison gap without adding accounts, cloud storage, email delivery, or personalized tax advice.

## Implemented Scope

- The homepage mounts `ScenarioHistoryPanel` behind the existing `scenario-history` feature flag.
- Users can save browser-local calculator snapshots.
- Saved scenarios are compared in a local table with conversion amount, taxable income, federal tax estimate, state tax estimate, total upfront cost, and break-even estimate.
- Invalid saved inputs are marked as needing valid input instead of displaying normal estimate values.

## Safety Boundary

The comparison table is educational and local-only. It does not:

- Upload calculator inputs.
- Create user accounts.
- Sync financial data to a server.
- Email reports.
- Recommend a conversion amount.
- Determine final state-law, agency, or tax-form outcomes.

## Validation

Regression coverage must verify:

- The homepage gates the module with `isFeatureEnabled("scenario-history")`.
- The panel saves, restores, deletes, and compares local scenarios.
- The comparison copy retains the educational and professional-review boundary.
