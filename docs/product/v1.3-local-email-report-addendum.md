# V1.3 Local Email Report Addendum

Date: 2026-06-10
Version: 1.0.223

## Purpose

This addendum implements the safest useful version of the V2 "email report" idea without adding a server-side email provider, user accounts, recipient collection, or cloud storage.

## Implemented Scope

- The homepage result action toolbar includes an `Email draft` action behind the `email-report` feature flag.
- The action builds a `mailto:` URL locally in the browser.
- The draft body uses the existing educational calculator summary and disclaimer.
- The draft does not specify a recipient address; the user chooses whether and where to send it.

## Safety Boundary

The feature does not:

- Send email from the website server.
- Store or collect recipient addresses.
- Upload calculator inputs.
- Create user accounts.
- Replace the print-ready HTML report.
- Turn the result into personalized tax, financial, legal, or investment advice.

## Validation

Regression coverage must verify:

- The generated URL uses the `mailto:` protocol.
- No recipient address is prefilled.
- The body retains the educational disclaimer and qualified professional review boundary.
- The generated draft does not contain recommendation, optimal-action, or "you should convert" language.
- The homepage gates the action with `isFeatureEnabled("email-report")`.
