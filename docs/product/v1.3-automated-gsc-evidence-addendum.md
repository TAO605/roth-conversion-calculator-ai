# V1.3 Automated GSC Evidence Addendum

Date: 2026-05-30

## Purpose

This addendum closes the loop created by `npm run seo:gsc-evidence`: priority URL evidence is now automated in GitHub Actions, not only available as a manual preflight command.

## Implemented Scope

- Updated `.github/workflows/seo-smoke.yml`.
- Added `GSC_EVIDENCE_BASE_URL`.
- Added a `Run GSC priority URL evidence check` step after `npm run seo:smoke`.
- Updated workflow tests so this automation cannot be removed silently.

## Workflow Order

1. Checkout.
2. Set up Node 22.
3. `npm ci`.
4. Wait 90 seconds after push-triggered production deploys.
5. Run `npm run seo:smoke`.
6. Run `npm run seo:gsc-evidence`.

## Operating Rule

Use the GitHub Actions SEO Smoke workflow as the public production SEO health gate:

- `seo:smoke` checks global SEO availability and compliance copy.
- `seo:gsc-evidence` checks Search Console priority URL readiness.

If the workflow fails, inspect which command failed before changing application code. A smoke failure and a GSC evidence failure imply different scopes.
