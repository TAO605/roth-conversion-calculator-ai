# V1.3 SEO Evidence Artifacts Addendum

Date: 2026-05-30

## Purpose

This addendum turns automated SEO checks into downloadable evidence. Each GitHub Actions SEO Smoke run now keeps JSON outputs for both the general production smoke check and the GSC priority URL evidence check.

## Implemented Scope

- Updated `.github/workflows/seo-smoke.yml`.
- Replaced plain `npm run seo:smoke` with `node scripts/seo-smoke.mjs | tee seo-smoke-result.json`.
- Replaced plain `npm run seo:gsc-evidence` with `node scripts/gsc-evidence.mjs | tee gsc-evidence-result.json`.
- Added `actions/upload-artifact@v4`.
- Artifact name: `production-seo-evidence`.
- Retention: 30 days.

## Evidence Files

- `seo-smoke-result.json`
- `gsc-evidence-result.json`

## Operating Rule

When Search Console request-indexing fails or a ranking/indexing incident is reviewed, use the latest `production-seo-evidence` artifact to confirm:

- homepage, robots, sitemap, llms, and YMYL wording checks,
- priority URL status,
- canonical URLs,
- sitemap inclusion,
- noindex status.

## Verification

- `npm test -- tests/core/seo-smoke-workflow.test.ts tests/core/release-notes.test.ts tests/core/ymyl-language-guard.test.ts`
- `npm test`
- `npm run build`
- `npm run seo:smoke`
- `npm run seo:gsc-evidence`
- Push-triggered GitHub Actions SEO Smoke run succeeds and uploads `production-seo-evidence`
