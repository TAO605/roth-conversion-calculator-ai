# V1.3 Tool-Only Homepage Addendum

This addendum records the homepage simplification requested after reviewing the mobile first viewport.

## Implemented

- Removed homepage primary navigation links for `Calculator`, `Explanation`, and `Sources`.
- Removed the marketing-style hero, CTA buttons, workflow explainer cards, visible method/source blocks, and visible FAQ section from the homepage.
- Kept the homepage focused on:
  - compact brand bar,
  - theme toggle,
  - single H1,
  - interactive calculator tool,
  - footer disclaimer and crawlable site links.

## SEO and YMYL Boundary

- FAQ structured data is no longer mounted on the homepage because the visible homepage FAQ was removed.
- Calculator, WebApplication, WebSite, WebPage, HowTo, and Organization structured data remain mounted.
- Official source and methodology content remain available through dedicated pages and footer/internal discovery, rather than occupying the homepage first experience.
- The calculator still retains educational boundaries, disclaimer copy, professional-review language, and source-linked supporting pages.

## Acceptance Evidence

- Homepage tests require the compact navigation and absence of explanation/source nav links.
- Homepage tests require the calculator to appear before footer/discovery content.
- E2E homepage smoke checks the calculator workflow without requiring the removed FAQ section.
