# V1.3 Search Console Exception Queue Addendum

Date: 2026-05-30

## Purpose

This addendum extends the Search Console operations loop with an exception queue. The goal is to avoid unnecessary site changes when Google Search Console has an account, DNS, propagation, or transient workflow issue.

## Implemented Scope

- Added `buildSearchConsoleExceptionQueue()` in `src/content/seo-monitoring.ts`.
- Rendered a `Search Console exception queue` section on `/seo-monitoring`.
- Tracked three current exception classes:
  - Domain property verification
  - Sitemap submission
  - URL Inspection indexing request

## Current Evidence

- URL-prefix property `https://www.roth-conversion-calculator-ai.shop/` is accessible.
- Domain property `sc-domain:roth-conversion-calculator-ai.shop` is not verified because Google did not find the DNS TXT verification token.
- `/sitemap.xml` was submitted successfully in Search Console.
- Search Console reported a successful read on 2026-05-30 and 120 submitted URLs.
- URL Inspection for `/seo-monitoring` initially showed `Discovered - currently not indexed`.
- Live URL test passed: the URL can be indexed, HTTP status was `200 OK`, resources loaded, and there were no JavaScript console messages.
- Two `Request indexing` attempts returned Google's transient error asking to try again later.

## Operating Rule

If all three are true:

- production `npm run seo:smoke` passes,
- sitemap submission succeeds,
- URL Inspection live test says the page can be indexed,

then do not change production code only because request indexing failed. Record the exception, wait several hours, and retry once in a later operations window.

## DNS Verification Rule

The verified URL-prefix property is enough to operate the canonical `www` site in Search Console. Domain-property verification is still useful for broad domain reporting, but it should be handled as a DNS operations item:

- add Google verification as a separate TXT record at the domain provider, or
- correctly merge it only if the provider requires one TXT value per host,
- wait for DNS propagation,
- retry domain-property verification.

Do not remove the existing SPF value while fixing Google verification.
