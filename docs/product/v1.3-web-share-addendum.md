# V1.3 Web Share Addendum

Date: 2026-06-10
Version: 1.0.224

## Purpose

This addendum implements the safest web-native interpretation of the V2 Apple ecosystem sharing idea. A standard website cannot guarantee dedicated AirDrop integration, but supported iOS and macOS browsers can expose AirDrop through the system share sheet when the Web Share API is available.

## Implemented Scope

- The existing `Share result` action now tries `navigator.share()` first.
- The share payload includes an educational title, short text, and the encoded calculator scenario URL.
- If native sharing is unavailable, cancelled, or blocked, the button falls back to copying the share URL to the clipboard.

## Safety Boundary

The feature does not:

- Claim guaranteed AirDrop availability.
- Install native Apple integrations.
- Upload calculator inputs to a server.
- Create user accounts.
- Replace the existing encoded share URL and local calculator persistence boundaries.

## Validation

Regression coverage must verify:

- The share payload uses an educational title and scenario URL.
- Native `navigator.share()` is used when available.
- Clipboard fallback remains available when native sharing is unavailable.
