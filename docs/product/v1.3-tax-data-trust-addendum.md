# V1.3 Engineering Addendum - Tax Data Trust

Date: 2026-05-30

This addendum supplements `docs/product/v1.3-current-state-gap-assessment.md` with the next executed engineering step: explicit tax-data trust metadata for YMYL SEO and user confidence.

## Implemented

- Added shared tax-data trust metadata in `src/core/tax-data/freshness.ts`: active tax year, last updated date, official IRS source URLs, update window, excluded interactions, and professional-review status.
- Rendered the metadata in `TaxDataFreshnessCard`, including direct IRS source links and a plain `Tax professional review pending` status.
- Added the same trust metadata to the public health payload so production checks can confirm the deployed tax-data state.
- Updated homepage source wording from broad reviewed-month copy to explicit last-updated copy.
- Added deterministic tests for source links, review status, and operational traceability.

## Compliance Boundary

- Do not claim CPA, EA, or professional review until written review evidence exists.
- Keep tax data language as educational estimate language, not guaranteed accuracy.
- Keep IRMAA, ACA subsidies, NIIT, AMT, tax credits, and state-specific deductions listed as not modeled unless full rule engines and inputs are implemented.
