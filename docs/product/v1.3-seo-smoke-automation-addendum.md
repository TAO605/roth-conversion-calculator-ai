# V1.3 Engineering Addendum - Automated SEO Smoke Checks

Date: 2026-05-30

This addendum turns the production SEO smoke command into a GitHub Actions workflow.

## Implemented

- Added `.github/workflows/seo-smoke.yml`.
- Runs `npm run seo:smoke` against `https://www.roth-conversion-calculator-ai.shop`.
- Supports manual `workflow_dispatch`.
- Runs after pushes to `main`.
- Runs once daily on a schedule.
- Waits 90 seconds after push events so the production alias has time to settle before checking the live site.

## Workflow Boundary

- The workflow does not require secrets.
- It does not deploy the site.
- It only verifies public production URLs and fails if SEO smoke checks fail.

## Why This Matters

This closes the technical SEO loop: deploys and daily production checks can now detect canonical, sitemap, robots, llms.txt, trust-copy, and high-risk YMYL wording regressions without relying only on manual review.
